# Bf 109 G-6 (AI bandit) — data notes

**Status: placeholder AI opponent.** This is not a validated Bf 109 model.

- Mass, wing area and span are representative G-6 figures.
- The aerodynamic table is currently a copy of the Spitfire estimate; the wing shape
  differs, so turn/stall behaviour is not representative.
- The DB 605 power curve is approximate and not sourced to a test report.
- Armament is modelled as one MG 151/20 and two MG 131s with representative rates,
  ammunition and relative damage.
- The visual is a recoloured Spitfire mesh.

The point of this data set is to give the AI a distinct engine/armament and a credible
silhouette for the combat loop. Replace the aero table and visual with measured Bf 109
data when available.
